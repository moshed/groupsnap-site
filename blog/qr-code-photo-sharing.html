QR code photo sharing for events

How it works, and the five questions worth asking before you pick a tool.

4 September 2026

What the code actually is

A QR code is a picture of a web address. That is the whole trick. The camera reads it, the phone opens that address, and the page at the other end is a private album belonging to one event. No photo is ever stored in the code, which is why a single code printed once can serve two hundred guests all night.

Because it is only a link, the interesting question is never the code. It is what the link opens.

The five questions

1. Does the link open an album, or an App Store page?

This is the one that decides whether your album fills up. A guest at a table with a drink in one hand will scan a code. They will not install an app, wait for it, open it, and find their way back to your event. If a tool's answer is "guests download our app", the code has been turned into an advert.

The good answer is that the link opens a web page they can upload from immediately — and, if an app exists, that the same link opens the app for anyone who already has it.

2. Is there a short code as well?

Codes fail. A phone camera struggles in dim reception lighting, someone's lens is smeared, an older guest has never scanned anything. A six-character code that can be read aloud across a room is the fallback that saves the evening.

Worth checking: whether the alphabet avoids ambiguous characters. GroupSnap's codes never contain O, I, S, 0, 1 or 5, precisely so "was that an oh or a zero" cannot happen when the code is being shouted over a band.

3. What does the free tier cap, and when does it bite?

Nearly every tool has a free tier and nearly all of them cap uploads — 50 is the common number. Fifty photos is one hour of one wedding. The cap will be reached, and it will be reached mid-event, which is the worst possible moment to be entering card details.

Read the cap and ask honestly whether your event will pass it. See our dated comparison for what each tool caps and what it costs.

4. How long do the photos stay up?

Two different clocks, and tools quote them separately: the upload window (how long guests can still add photos) and the storage window (how long the gallery stays online). Typical numbers are 3–12 months and 12–14 months. If you want the album to still be there in five years, none of these are a substitute for saving the photos somewhere you control.

5. What happens on bad venue Wi-Fi?

Halls are famously terrible for signal. A tool that queues an upload and retries is worth more on the night than any feature list. Ask whether a failed upload is visible to the guest or silently dropped, and tell people the album stays open afterwards so they can finish from home.

Printing the thing

  • Size: about 3 cm (1.2 in) square scans at arm's length. On a table card, 4–5 cm is comfortable.
  • Contrast: dark code on a pale background. Reversed-out white-on-dark codes scan badly under warm lighting.
  • Quiet margin: leave clear space all round. Text crowding the edge breaks the scan.
  • Print the code underneath, in large letters, always.
  • One per table, not one by the door. People scan what is in front of them.
  • Test it with a phone that is not yours, before the day.

A note on privacy

An album protected by a short code is protected about as well as a short code protects anything: anyone who has the code, or a photo of your poster, can get in. That is usually the right trade for a wedding, where the alternative is that nobody joins. It is the wrong trade for anything genuinely sensitive. Some tools — GroupSnap included — can additionally require a guest to be physically inside a radius around the venue, which is a much better fit for an event that should not be joinable from a screenshot.
